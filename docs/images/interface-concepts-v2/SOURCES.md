# 界面来源

版本：CC98 Reborn **0.4.4**；仓库提交 `0616c57eba91dad58f78be8cc6418ceb52929d47`。

图片使用生产 HTML、JavaScript 和 CSS 渲染。页面类场景在隔离的 CC98 原站 React 前端中加载真实扩展；独立窗口和弹窗直接使用对应生产组件。帖子、账号、收藏和私信均为示例数据，未读取真实账号资料。

| 图 | 生产界面来源 |
| --- | --- |
| 01、06、16、17 | 原站前端 + `src/content.js`、`src/styles.css`、`src/interface-styles.css` |
| 02 | 插件设置页及其主题、配色控件 |
| 03、04、05、18 | 收藏夹分享、用户备注、私信组件及其生产样式 |
| 07、08、09 | 对话追踪、全文搜索窗口及实际扫描结果 |
| 10 | 设置页的发言屏蔽条件组件 |
| 11、13、14、15 | 原站编辑器 / 帖子 / 收藏页面 + 图片查看器、双区编辑和图片收藏组件 |
| 12 | `popup/archive.html`、`popup/archive.js`、`popup/archive.css` |

表情与图片查看器中的秋季封面来自原站静态资源；私信中的头像、图片为示例素材。对话图使用插件支持的 90% 字号；保留各主题自身的排版、控件、滚动区域和提示文字。

原始截图只进行等比排布；外部添加留白、阴影和斜线分隔。没有重新绘制控件或改写产品文案。第 15 张每一侧分别放置图片收藏区域与编辑器中的快速选择面板。
