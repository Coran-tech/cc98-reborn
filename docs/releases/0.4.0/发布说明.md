# CC98 Reborn 0.4.0

这版继续补全屏蔽规则，加入可选的本地语义识别，并整理部署入口和规则编辑体验。

- 标题匹配支持 `/正则/i`，普通关键词照常使用。标题和发言条件输入时自动检查语法，无效规则不能加入；正则在独立线程限时运行。
- 新增实验性本地语义屏蔽，默认关闭。用户自行下载、部署后手动接入，可选择 COLD、Horizon 或 MiniLM，调整阈值和话题标签；命中后仍可展开原文。
- 独立语义工作台支持真实推理、模型比较和文本测试，模型及 Python 环境不包含在插件中。部署源码包可直接从插件下载。
- 精简语义工作台和设置界面，移除不可用的仓库目录链接。
- 调整 ASCII 屏蔽条的“显示”按钮，保持横向紧凑排版；帖子浏览数移至标题右下方。

0.3.9 的全部功能继续包含在本版中。

安装：解压 `cc98-reborn-0.4.0.zip`，在 Edge／Chrome 扩展管理页加载解压后的目录。已有安装可覆盖文件后重新加载扩展，再刷新论坛页面。

测试版仍使用固定的 `dist/cc98-reborn-beta/`，版本显示保留 beta 和 build 编号；正式包显示 `0.4.0`。
