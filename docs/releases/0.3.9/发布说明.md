# CC98 Reborn 0.3.9

这版主要加上网页内帖子侧窗，继续优化浏览性能，并补全全文搜索和首页排版。

- 屏蔽规则里可以直接选择表情了，沿用编辑器的六组表情面板，点选后填入编号，无需手动查找代码。

- “黑名单”更名为“屏蔽规则”。新增风评、踩量、赞踩比和赞踩总数条件，支持与文本、表情、正则逻辑组合；快捷设置可同时限定最低票数。风评按本楼评分记录净增减计算，数据缺失时不误当成 0，原有屏蔽设置继续生效。

- 黑名单支持发言内容规则，可按特定文本或 `[ac01]` 等表情的出现次数屏蔽，也可用 AND／OR／NOT、括号和正则组合条件。提供快捷添加、语法校验、删除与备份；引用和签名不计入，复杂正则在本地独立线程限时检测。

- 十大、新帖的帖子标题支持右侧打开。主页面保持内容和滚动位置，视觉上向左收起；侧窗沿用插件 UI，省略重复顶栏，支持翻页、回复、调整宽度和新标签页打开，关闭后释放资源。
- 侧拉窗默认开启，可在 popup 或个人中心插件设置的“浏览与阅读”中关闭；两处设置同步，关闭后恢复普通链接打开方式。
- 修复侧窗内问号提示“无效的帖子地址”，正确识别侧窗帖号并定向校验当前账号，支持隐私确认、计数、点击及翻页后操作。
- 用户黑名单也会隐藏引用块中可识别的对应用户发言，覆盖帖子、侧窗、我的回复和查看对话；嵌套及同框多作者分别处理，保留正常引用和自己的正文，移除黑名单后可恢复原文。
- 全文搜索新增楼层作者用户名／UID，以及 `[ac01]`、`[cc9801]`、`[tb01]` 等表情编号匹配。复用已读页面与文本索引，换关键词不用重新扫描；匿名用户仅匹配公开身份。
- 减少帖子同步时重复生成已有楼层、原生弹窗空闲扫描和 ASCII 全页面装饰处理，保留草稿、光标、动态内容及图片懒加载。
- 首页“只留十大”的内容宽度与顶栏对齐，标题和版本信息上下排列；Reborn 保留双列卡片，ASCII 保留单列列表并小幅收紧字号、行高和留白。长标题可换行，空间不足时正常滚动。
- 测试版使用固定的 `dist/cc98-reborn-beta/` 目录，并显示 `beta 0.3.9 (build 编号)`，后续覆盖后重新加载即可；正式包只显示 `0.3.9`。本地模拟论坛已移到独立目录。

0.3.8 的全部功能继续包含在本版中。

安装：解压 `cc98-reborn-0.3.9.zip`，在 Edge／Chrome 扩展管理页选择解压后的目录。若沿用固定安装目录，替换文件后重新加载扩展，再刷新论坛页面即可。
