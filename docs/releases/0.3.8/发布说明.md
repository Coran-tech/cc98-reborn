# CC98 Reborn 0.3.8

这版主要补上帖内全文搜索，并继续修整加载体验和 ASCII 风格。

- 十大和新帖支持网页内侧拉窗：点击标题在右侧打开完整帖子，主页面内容和位置保持不动，视觉上向左收起。侧窗内可以翻页、回复，拖动左边缘调整宽度；关闭后释放页面资源，随时回到刚才的列表。
- 新增“全文搜索”，入口在收藏左侧。开始前提醒读取所需时间，确认后串行限速读取；支持后台搜索、关键词高亮、选择是否包含引用、暂停／继续、重试和刷新内容。
- 全文搜索也能搜索楼层作者的用户名／UID，以及 `[ac01]`、`[cc9801]`、`[tb01]` 等表情编号；已经读取的页面直接复用，换关键词不必再读一遍。
- 全文搜索与“查看对话”共用页面缓存和请求队列。同一标签页内翻页、刷新后复用已读内容，未完成的搜索可以继续；离开本帖暂停，切换账号隔离缓存与结果。
- 第一次进入帖子直接显示插件布局，内容随后填入；预热第一页改为后台静默读取。优化刷新和切页时的抽动、旧内容闪现与阅读位置恢复。
- 继续补齐 ASCII：弹窗、悬浮窗、框线和控件统一直角与等宽文字；修复十大标签对齐、排名变动与稍后再看重叠，以及签名档挤入作者栏。
- 帖子分页栏的输入框、页码及跳转／分享／全文搜索／收藏按钮统一高度；全文搜索使用副主题色，适配明暗、窄屏和字体缩放。
- “首页只留十大”与顶栏保持相同内容宽度，标题和版本信息上下排列，卡片、列表保留适度留白；Reborn 双列、ASCII 单列，长标题可换行，空间不足时正常滚动。
- 减少同步时反复生成已有楼层的开销，ASCII 改为局部更新与按需重画字符边框，修复原生弹窗和分页空闲时的重复处理。保留现有功能，并回归检查懒加载、翻页、编辑、对话搜索和主题还原。

0.3.7 的全部功能继续包含在本版中。

安装：解压 `cc98-reborn-0.3.8.zip`，在 Edge／Chrome 扩展管理页选择解压后的目录。若沿用固定安装目录，替换文件后重新加载扩展，再刷新论坛页面即可。
