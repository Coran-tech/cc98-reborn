# CC98 Reborn 0.3.7

本版主要重做主题设置，并补齐消息、个人中心和编辑页面的适配。

- 明暗和配色独立：白昼、黑夜、按本地时间自动切换；双色预设、自定义主色／副色与 HEX 输入。配色应用于论坛页面元素。
- 新增复古 ASCII 界面风格（实验性）：字符边框、等宽文字、紧凑列表、两列帖子与直角控件，编辑和文件下载使用文字标记。
- 新增私信联系人置顶，优化表情尺寸、近期联系人排版和消息分页。
- 个人中心底部新增独立插件设置子页，与 popup 共用全部设置。
- 新增个人配置备份／恢复，包含主题、阅读显示、黑名单、备注和置顶，导入前验证与预览。
- 适配版面“发投票”及投票编辑页，保留原站选项、校验和编辑行为。
- 修复“我的回复”中引用未渲染，以及引用图片残留 Markdown 标记／错误下载框的问题。
- 统一元信息和关注入口，去掉装饰 emoji，取消关注加号悬停展开。

“查看对话”、收藏夹分享和本地用户备注继续包含在本版中；它们已在 0.3.6 加入。问号、扩展语法和 UBB／Markdown 互转仍保持实验性。

安装：解压发布包，在 Edge／Chrome 扩展管理页选择干净的 `cc98-reborn-0.3.7` 目录。升级前可备份个人设置；更新固定安装目录后重新加载扩展并刷新论坛。

本地 ZIP 的生成不会自动创建 GitHub Release，也不会修改 CC98 介绍帖。介绍帖正文和 24 张功能概念图另见 `intro/`。
