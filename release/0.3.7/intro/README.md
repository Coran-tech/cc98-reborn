# CC98 Reborn 0.3.7 介绍帖素材

- 原帖：https://www.cc98.org/topic/6521472
- 参考：用户提供的 0.3.5 介绍帖 MHTML；保留 lz／uu、Vibe Coding 提醒和食用方法的语气。
- 文案：介绍帖正文.md 含本地配图；介绍帖正文_UBB.txt 可直接粘贴到原站 UBB 编辑器。
- 配图：images/ 下 24 张 1440 × 900 PNG，每项功能一张，按配图顺序.txt 对应小标题。总览.png 便于挑选。
- 预览：打开预览.html 可浏览全部配图和文案。

## 发帖前

1. 用建议标题.txt 更新标题。
2. 粘贴介绍帖正文_UBB.txt。这个文件没有失效的图片占位 URL。
3. 在对应段落后用 CC98 原生上传功能插入本地 PNG；原帖已提供的旧截图可按需要保留。
4. 下载链接仍指向 GitHub Releases。0.3.7 当前交付的是本地发布包，发布页是否已上传请以实际发布状态为准。

所有概念图均为功能示意，不是真实页面截图；示例账号、帖名、排名、分数、分享串和 JSON 结构为虚构。标为“新增功能”的部分从旧帖 0.3.5 之后陆续加入；已在 0.3.6 出现的功能没有写成 0.3.7 首次新增。实验性功能及影响用户判断的限制保留说明。

本地设置备份不包含登录凭证、API 密钥、草稿或稍后再看。备注与置顶的账号条目按原账号恢复。问号使用独立服务，默认关闭，当前直连授权已接入，WebVPN 问号授权未接入。

## 渲染源

features.json 保存配图清单与对应正文，concepts.html 是 HTML/CSS/SVG 概念图源。build.cjs 构建文本和预览，render.cjs 用本地 Edge / Playwright 导出 PNG，全程不访问论坛。
