# CC98 Reborn

本地语义模型实验：`experiments/semantic-lab` 提供 COLD、Horizon、MiniLM 对比工具。“屏蔽规则”新增默认关闭的实验性语义屏蔽；用户自行下载并部署本地服务、手动填写令牌并授权后，可选择模型、阈值及话题标签。推理环境和模型独立存放，不放入插件包。部署及接入见该目录 README。

面向 Chrome / Edge 的 CC98 论坛界面重构扩展。

它的主要目标很简单：让 CC98 的页面更统一、更清爽，也顺手补上一些日常浏览真正用得上的便利功能。扩展会在浏览器本地读取原页面已经加载的内容，构建新的阅读界面；发帖、回复、上传、收藏、评分、关注、私信等关键操作则尽量继续调用原站逻辑。

当前版本：`0.4.2`

## 它改了什么

### 统一的界面

- 重构首页、十大、新帖、关注、精选、版面、搜索、帖子、用户中心、消息中心和编辑页面。
- 顶栏“稍后再看”右侧和个人中心导航最底部均有“插件设置”，打开独立设置子页，包含弹窗里的全部设置和账号、更新等功能；两处共用本地保存数据并即时同步。可选功能按页面布局、浏览与阅读、显示与图片、回复与互动归入对应区块，图片预热开关与时长放在一起。设置页不等待原站个人中心数据，界面就绪即撤掉遮罩。修改选项不会重载表单，停用美化后仍可重新进入设置并启用。
- 设置最底部“恢复默认”旁可备份和导入个人配置。JSON 文件包含主题、阅读／显示设置、屏蔽规则、用户备注、私信置顶与版面置顶；导入前显示数量，覆盖同名配置并保留其他数据。备注和私信置顶按原账号恢复；登录凭证、API 密钥、稍后再看和草稿不在备份范围内。
- 明暗与配色独立设置：白昼、黑夜、自动三种模式，六组主色／副色配色预设和自定义方案。自动模式按本地时间切换，默认 07:00 白昼、19:00 黑夜，可调整；同一套配色同时适配明暗背景，旧主题自动迁移。常见弹窗、下拉菜单、分页、日历和 Ant Design 原生组件保持一致。
- 论坛页面的主色用于导航、搜索、发帖和当前分页；副色用于版面标签、内容链接、引用边线和辅助操作。切换配色直接更新页面元素，评分红绿、热评和锁帖提示保留对应的状态颜色。
- “界面风格”独立于明暗和配色。Reborn 保留当前界面；ASCII / BBS（实验性）使用字符边框、等宽字体、直角控件和彩色文字，帖子在宽屏采用作者／正文两列，窄屏自动上下排列，主题索引改为紧凑列表；编辑、下载及十大变动使用 ASCII 文字标记。页面框线、弹窗、悬浮菜单、图片查看器和插件设置同步适配。风格选择支持跨标签同步和个人设置备份，切换保留正在阅读与编辑的内容。
- 配色预设用双色点显示；“自定义”支持分别选主色／副色或输入 HEX 颜色。明暗模式自动适配亮度，原始颜色独立保存，切换预设后仍可恢复自定义方案。
- 提供可选的左侧效率栏；常规顶栏和效率栏均有重新整理的用户、消息与账号菜单。
- “我的收藏”新增“分享收藏夹”：选择分组后导出完整收藏为字符串；粘贴字符串可预览帖子并选择目标分组批量导入。已有收藏保持原分组，支持停止、继续和失败重试。每次最多分享 2000 条，字符串仅包含分组名、帖子编号和标题。
- 本地用户备注：在“我的关注”和用户主页编辑最多 80 字的备注，帖子作者旁保留原用户名并显示备注。备注按当前账号和目标用户 UID 保存，用户改名后仍匹配；同一浏览器多标签页同步，仅自己可见，默认不跨设备同步。
- 适配 CC98 直连与浙江大学 WebVPN，站内导航会尽量保留当前访问方式。
- 返回首页或进入用户页时使用短时主题幕布，减少原版页面在重构前一闪而过。

### 更舒服的帖子阅读

- 所有重构的帖子卡片列表共用帖子侧窗，包括十大、新帖、关注、精选、版面、搜索结果和稍后再看。直接点击帖子标题，会在网页右侧打开独立帖子侧窗，打开时保留主列表内容与阅读位置，在左侧按剩余宽度重新排版。popup 和个人中心“插件设置”的“浏览与阅读”中可切换“帖子侧拉窗”，默认开启；关闭后沿用普通链接打开方式，并释放已打开的侧窗。侧窗沿用插件界面，省略重复的论坛顶栏，可翻页、回复，拖动左侧边缘调整宽度；分割线中央的收起按钮可关闭侧窗，恢复左侧布局并释放资源。同帖翻页、引用楼层和回复编辑留在侧窗，其他链接遵循“链接在新页面打开”：开启时另开标签页，关闭时跳转主页面。作者、版面链接及 Ctrl／Command、Shift 和中键继续按原方式打开。
- 侧窗为非模态：右侧显示帖子时，左侧列表仍可滚动、继续加载、按需渲染和点击；点击其他帖子直接替换右侧并释放旧页面。两侧分别滚动，左侧普通链接沿用链接打开偏好，键盘焦点可自由离开侧窗。关闭时保留左侧新的阅读位置；主页面实际跳转时关闭侧窗，图片查看器等同地址历史状态不影响右侧。
- 侧窗打开后，左侧卡片单列铺满可用区域，保留边距，拖动侧窗宽度时同步重排；关闭后恢复正常布局并保留正在阅读的帖子。窄顶栏将品牌与账号并排，导航、搜索分行；左侧右下角的圆形火箭按钮可独立回到顶部，不影响右侧阅读位置。浏览模式、稍后再看等控件收进“浏览工具”，展开即可使用。取消左右位置选择，旧备份中的该偏好会被忽略。
- 重构正文、引用、Markdown 回复、签名档、评分记录、投票、热评和楼主标识。
- 用户屏蔽规则同时隐藏可识别作者的引用发言，适用于帖子、侧窗、“我的回复”和“查看对话”。嵌套引用及同框多个作者分别处理，保留正常引用和回复者自己的正文；移除规则后恢复原文。用户名精确匹配，UID 仅使用引用头或已加载页面中的公开对应关系。
- 图片支持点击放大、鼠标焦点缩放、拖动、前后切换和保存。
- 正文、签名档和对话弹窗中带网页超链接的图片，点击后可选“查看大图”或“前往链接”。普通图片和指向图片文件的链接仍直接打开查看器；跳转沿用链接打开设置，侧窗中继续遵循主页面／新标签页偏好。
- 帖子图片预热默认关闭，可在插件弹窗和设置页的“显示与图片”中按需开启并调整预热时长。
- 从后续页进入帖子时，第一页在后台静默预热，当前页立即展示；楼主标记和热评高亮随后补齐，不跳转前台、不显示预热遮罩。同帖短时间内复用读取结果，关闭开关或离开帖子时取消未完成的任务。
- 刷新、切页时立即显示插件的导航、标题区和正文框架，尚未到达的数据在插件内加载、原位填充，全程隐藏原站布局。插件外框与导航保持挂载，相同数据的延时任务不重复重建；刷新后恢复阅读位置，同页同步保留阅读锚点，翻页在新页就绪后统一定位。
- 首次打开和翻页时，从原站内容快照及懒加载组件恢复图片地址；即使预热关闭，也能在重构页面滚动加载图片。重复图片保留各自位置，隐藏图片仍需点击查看。
- 引用内被部分解析的 Markdown 图片会清理残留标记和错误下载框，保留图片、正常附件下载及代码中的原样语法；正文和“查看对话”使用相同处理。
- 适配普通视频、哔哩哔哩视频、隐藏图片、文件下载和 APlayer 音频。
- 评分记录默认展开并统计风评变化；正负数在明暗主题下分别使用清晰的绿色与红色。
- 识别锁定主题、锁帖提示、跨页楼层链接和跨主题引用。
- 楼层操作区的“查看对话”可在单个弹窗中递归追溯上游引用、查找本帖的下游回复，并切换追溯中心。引用按父子关系逐级缩进，分支紧跟父楼层；多父引用提供定位入口。弹窗复用当前主题、表情大小和图片查看器。按需静默读取其他页，支持停止、继续和失败重试；已读页面按帖子暂存，同帖翻页、刷新标签页、切换楼层或重开弹窗时复用，只补读未完成的页面，可点击“刷新对话”获取新回复及编辑。原页面、滚动位置和草稿保持不变。跨帖引用可追溯上游，下游仅检索当前帖；未读取或已删除楼层会明确提示。
- 收藏左侧的“全文搜索”在独立窗口中搜索本帖所有楼层，支持正文关键词、楼层作者的用户名／UID，以及 `[ac01]`、`[cc9801]`、`[tb01]` 等表情编号；显示进度、命中高亮和原楼层链接，可选择是否包含引用，匿名用户仅匹配公开身份。开始或刷新内容前显示等待提醒并确认，逐页串行读取，未缓存页面的读取至少间隔一秒；与查看对话共用已读页和队列，切换关键词复用已有页面与文本索引。关闭弹窗后在当前标签页继续搜索，同帖整页翻页或刷新可恢复进度，支持暂停、继续和失败重试；离开本帖时暂停，重新打开该帖后可继续。关键词和进度按账号保存在标签页会话中，不进入个人设置备份。
- 帖子作者头像可展开资料卡，并继续使用原站的关注和私信功能。

### 发帖与编辑

- 适配发主题、回复、编辑主题和编辑回复页面。
- 版面“发投票”入口及投票编辑页统一主题样式，保留有效天数、最多可投数量、投票后结果可见和原生 2–20 项增删规则；支持 UBB／Markdown 切换与窄屏布局，参数校验由原站完成，标题／正文草稿与普通主题分别保存。
- UBB 模式提供上下双区编辑：上方直接编辑渲染内容，下方编辑带语法高亮和逻辑行号的 UBB 源码；两边实时同步并可独立拉伸，中间分隔线也可拖动，工具栏另有手动“同步”和基于 `0.3.1` 的“旧预览”备用入口。
- 保留原站 UBB 工具栏、上传、表情、颜色、字号、链接、图片、视频和音频能力。
- 双区工具栏的“扩展”可插入并预览引用、分割线、可编辑代码块、内嵌 Markdown、数学公式、原样文本、命名字体、1 至 6 行列的表格和折叠图片；自动导览目前暂停，提交内容仍是原站 UBB 源码。
- 双区工具栏的“互转”可在 UBB 与 Markdown 间转换常用语法；先预览和修改结果，再手动替换。无法等价转换的格式会提示，回复可见等权限内容禁止直接替换。
- 颜色面板支持常用色、透明色和快速渐变色。
- 适配原站 Markdown 编辑器，并为输入法提交与预览切换提供本地过渡预览。
- 发帖、回复和编辑均支持按页面与账号保存的本地草稿。
- 可选为普通回复加入 CC98 Reborn 小尾巴；匿名回复和心灵之约版面会自动停用。
- 个人资料的签名档使用同样的双区 UBB 编辑方式；为避免无法可靠回译，签名档编辑器不提供表情选择器。

### 搜索与稍后再看

- 适配主题、用户、版面、版内和全站搜索类型。
- 搜索联想只在本地分析当前输入，不会把搜索词发送给外部 AI 服务。
- 搜索历史按 CC98 用户 ID 保存，支持单条删除与全部清空。
- 搜索结果可按原顺序、时间或浏览量排序。
- 新帖、关注、精选和搜索结果右侧提供“稍后再看”侧栏，支持搜索、翻页、已读状态和删除。
- 这些侧栏下方提供等宽的“回到顶部”按钮，窄屏布局中仍会紧跟稍后再看组件。
- 完整“稍后再看”页面支持导入、导出和清除已读；数据按用户 ID 隔离保存在本地。

### 其他便利功能

- 首页可只保留十大，并记录排名变化。内容宽度与顶栏对齐，Reborn 保留双列卡片，ASCII 使用单列列表；标题、行距和留白优先保持可读，空间不足时正常滚动。
- 主题卡片可选择始终展开附加信息并关闭悬浮展开动画，默认仍保留原来的悬浮交互。
- 版面支持本地置顶；锁定主题会显示锁标识和警戒斜纹。
- 近期私信联系人右侧的图钉可置顶／取消置顶，最新置顶排在最前；按账号保存并跨标签同步。未加载到近期列表的置顶用户仍保留打开入口，原生会话、未读状态和草稿保持原有行为。
- 图片和列表内容可在滚动时从原页面无感同步到新 UI。
- 支持浏览记录、我的收藏、屏蔽规则页面和个人中心常用入口。
- 支持手动及定时检查 GitHub Releases 中的新版本。
- 提供显式的 CC98 Cookie 与站点数据清理入口，用于处理缓存异常或刷新十大。
- 可选的实验性“问号键”：在楼层的赞与踩之间显示问号和计数；使用前需同意独立隐私说明并完成同账号 CC98 OpenID 授权，默认关闭。

## 安装

1. 前往 [Releases](https://github.com/Coran-tech/cc98-reborn/releases) 下载最新 ZIP。
2. 将 ZIP 解压到一个固定文件夹。安装后不要随意移动或删除该文件夹。
3. 打开 `edge://extensions/` 或 `chrome://extensions/`。
4. 开启“开发人员模式”。
5. 点击“加载解压缩的扩展”，选择刚刚解压得到的文件夹。
6. 打开 [CC98](https://www.cc98.org/)，扩展会自动生效。

升级时，使用新版本文件覆盖原文件夹，或解压到新文件夹后在扩展管理页重新加载。

开发仓库中还包含论坛参考源码和测试依赖，请勿直接把整个项目根目录加载为扩展。运行打包脚本后，可直接选择 `dist/cc98-reborn-<版本号>/`；这是不含 `reference/`、`tests/` 和第三方测试密钥的干净目录。

## 基本使用

点击浏览器工具栏中的 CC98 Reborn 图标，可以：

- 开启或暂停界面重构。
- 在界面风格下调整“页面布局”：首页只保留十大、帖子卡片默认展开、左侧效率栏；明暗与配色独立选择。
- 在“浏览与阅读”中切换帖子侧拉窗、链接新标签页和后台预热第一页。
- 在“显示与图片”中调整字号、表情大小，按需开启图片预热并设置时长。
- 在“回复与互动”中切换回复小尾巴和实验性问号键。
- 设置版面、标题匹配和 UID 屏蔽规则。标题支持普通关键词和 `/正则/i`，输入时自动检查语法；正则在独立线程限时匹配。
- “屏蔽规则”的“发言条件”页支持按正文文本、表情编号的出现次数，以及本楼风评、赞数、踩数、赞踩比、赞踩总数折叠发言。输入旁的“选择表情”复用编辑器六组表情面板，选中即填入标准编号。快捷输入可添加次数或数值条件，并以“且／或”拼入高级表达式；支持 AND／OR／NOT（且／或／非）、括号与正则，例如 `"[ac01]" > 3`、`("广告" OR "推广") AND NOT "讨论"`、`/加[微薇]信/i >= 2`、`风评 < -3 OR (赞踩比 < 0.5 AND 赞踩总数 >= 20)`。多条规则任一命中即折叠；正文不含引用和签名，文本不区分大小写且按不重叠次数统计。风评是该楼完整评分记录里的风评值净增减；赞踩比为赞÷踩，有赞无踩视为无限大，零赞零踩、缺失数字或未展开完整的评分记录不判定。规则纳入个人设置备份，兼容旧黑名单配置；本地计算不额外请求服务器，正则在独立线程限时运行，异常会在规则页提示。
- 绑定或退出 CC98 OpenID。
- 检查更新、查看项目信息或清理 CC98 站点数据。

页面顶栏中的“同步”不是普通的浏览器刷新：它会重新读取原页面目前已经加载的内容，并同步到重构 UI。

新帖页试验性地按需挂载视口附近的卡片和图片。需要浏览器页内查找时，可在“浏览方式”中点“显示全部”；再点“恢复按需显示”切回。已加载的帖子数据保留，原站列表不删除。

启用问号键后，在 CC98 直连帖子的楼层中点击 `?`，阅读隐私说明并确认，再完成 OpenID 授权。此后页面会显示已加载楼层的问号计数；再次点击可取消自己的问号。此实验暂不支持 WebVPN 授权，也不替代原站的赞、踩、评分或回复。

## OpenID 与水印

登录 CC98 后，扩展会要求绑定同一账号的 CC98 OpenID，并通过 UID 检查网页账号与授权账号是否一致。

绑定时采用授权码 + PKCE：

- 临时 access token 只用于读取 `/me`，随后丢弃。
- 扩展只保存用户名、UID、绑定时间和水印所需的本地身份摘要。
- 水印在本地绘制为两行 Consolas 文字：第一行为前补零至八位的 UID、两个空格、前补零至八位的当前帖号；第二行为八位用户水印（已绑定 OpenID 的 `watermarkId` 前八位）紧接十位秒级 Unix 时间戳，中间不加空格，每秒更新。UID 与用户水印使用同一份本地绑定摘要。非帖子页的帖号为 `00000000`。侧拉窗与主页面共用一层水印，帖号跟随当前侧窗；关闭侧窗后恢复主页面帖号。
- 当前版本不会定时重新授权或刷新 `/me`；身份摘要会一直使用到重新绑定或解绑。
- WebVPN 授权会通过独立桥接脚本恢复回调，但不会上传论坛页面内容。

## 数据与隐私

扩展不会把帖子正文、标题、图片、私信、搜索词、草稿或插件设置上传到问号服务。问号功能默认关闭；开启并确认隐私说明后，才会与独立 HTTPS 服务通信。

可能发生的网络访问仅包括：

- 用户正在访问的 CC98 或 WebVPN 页面及原站资源。
- 用户点击“查看对话”后，按当前访问方式读取相关帖子页面；原站可能据此更新浏览量、足迹或已读状态。对话缓存按账号隔离，在当前标签页保留最近 6 个帖子的已读页面。内存保留当前帖的各页，并将内容写入 CC98 站点的标签页会话存储，以便整页翻页和刷新后复用；会话快照上限 4 MiB，优先移除旧帖，超出快照容量的大帖会在跳转后补读。关闭弹窗不会清空缓存，切换账号不复用旧账号内容，手动“刷新对话”会重新读取。缓存不进入个人配置备份，也不上传到问号或其他外部服务。
- 用户主动触发的 CC98 文件上传、下载和站内操作。
- 用户主动绑定时访问 CC98 OpenID 和 `/me`。
- 检查更新时读取公开的 GitHub Release 信息及备用镜像。
- 可选问号功能在授权时发送 CC98 OpenID ID Token 以换取短期会话；授权后查询或切换问号时发送数字帖号和楼层号。服务端使用身份摘要限制每个账号对每个楼层只有一个当前问号状态，普通用户只能查询汇总计数和自己的状态；服务端运营方仍能接触服务端数据。

稍后再看、版面置顶、草稿、搜索历史、屏蔽规则和 OpenID 摘要均保存在浏览器本地。使用“清除 CC98 Cookie 与站点数据”会同时删除 CC98 页面自身保存的本地数据，可能包括上述内容，请先导出需要保留的数据。

问号功能的服务端尚无法独立确认楼层存在性或原站访问权限，请勿将实验功能视为原站官方能力；目前仅在直连页面验证。AI 搜索联想和高级模糊搜索的外部接口当前保持停用。

完整说明见 [PRIVACY.md](./PRIVACY.md) 和[问号功能独立隐私说明](https://question.coranqwq.xyz/privacy)。

## 已知限制

- 原站页面结构变化后，部分适配可能暂时失效。
- WebVPN 响应较慢时，重构界面和图片出现时间会比直连更晚。
- 一些复杂操作会复用并移动原站 DOM 控件，因此扩展与其他大型页面重构脚本可能互相影响。
- OpenID 的 WebVPN 授权依赖学校 WebVPN 对相关域名和回调地址的代理行为。

## English Summary

CC98 Reborn is a Chrome/Edge extension that rebuilds common CC98 pages into a cleaner, theme-aware interface while reusing native CC98 controls for important actions whenever possible.

It supports direct CC98 access and ZJU WebVPN, improves post reading and media viewing, provides local drafts, search history, per-user read-later storage, board pinning, user hover cards, update checks, and optional OpenID-based local watermarking. An experimental question reaction is available on direct CC98 pages and is off by default.

The extension does not upload posts, private messages, search terms, drafts, or settings to the external question service. If users enable and consent to the optional question reaction, an OpenID ID Token and numeric topic/floor identifiers are sent to that service. See [PRIVACY.md](./PRIVACY.md) and the [question feature privacy notice](https://question.coranqwq.xyz/privacy) for details.

Install the latest package from [GitHub Releases](https://github.com/Coran-tech/cc98-reborn/releases), extract it to a fixed folder, then load that folder from `chrome://extensions/` or `edge://extensions/` with Developer mode enabled.
